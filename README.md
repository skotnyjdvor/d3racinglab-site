# d3racinglab.com

Static site (HTML/CSS/JS, no build step) served by GitHub Pages at https://d3racinglab.com.

- `index.html`: the page, with inline styles and script
- `assets/`: logo (SVG) and favicon
- `CNAME`: custom domain for GitHub Pages

## Render

`render.yaml` describes the same site as a Render static site (no build step, served from the repo root) with d3racinglab.com and www.d3racinglab.com as custom domains.
